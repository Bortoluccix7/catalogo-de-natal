# Lisianthus — Coleção Especial de Natal

Site responsivo em HTML, CSS e JavaScript puro.


## Funcionalidades
- Banner oficial da coleção no hero.
- Catálogo com os 10 produtos informados.
- Opções de formato e sabor por produto, quando aplicável.
- Filtros, busca e sacola com quantidades e subtotal.
- Pedido enviado pelo WhatsApp com as escolhas do cliente.
