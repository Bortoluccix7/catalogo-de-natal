# Lisianthus — Coleção Especial de Natal

Site responsivo em HTML, CSS e JavaScript puro.

## Como visualizar
Abra `index.html` no navegador. Mantenha a pasta `assets` junto dos arquivos.

## Antes de publicar
1. Abra `script.js`.
2. Altere `WHATSAPP_NUMBER` para o número que receberá os pedidos, com código do país e DDD.
3. Revise as opções e informações dos produtos.
4. Confira a disponibilidade e os preços antes de divulgar.

## Funcionalidades
- Banner oficial da coleção no hero.
- Catálogo com os 10 produtos informados.
- Opções de formato e sabor por produto, quando aplicável.
- Filtros, busca e sacola com quantidades e subtotal.
- Pedido enviado pelo WhatsApp com as escolhas do cliente.
